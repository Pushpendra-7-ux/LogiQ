### Quick Start

```bash
# Fetch Flutter dependencies
flutter pub get

# Run on Web (Chrome)
flutter run -d chrome

# Run on macOS Desktop
flutter run -d macos

# Run on Mobile (Android / iOS)
flutter run
```
